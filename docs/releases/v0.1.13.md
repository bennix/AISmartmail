# AISmartmail v0.1.13

Released: 2026-11-17 (Asia/Tokyo). App version: 1.08, build 5.

## Changes

- Preserve unnamed MIME inline image parts and resolve `cid:` image references from downloaded attachments.
- Remove styles, scripts, document metadata and comments from HTML-derived text previews; decode common HTML entities.
- Prefer the mail's actual plain-text part even when its HTML alternative comes first.
- Repair cached plain text and previews that match the previous tag-only HTML conversion, and mark those messages for reindexing.
- Fall back to plain text when an HTML body is empty.

Previously discarded inline attachments cannot be recovered from the cached HTML alone; those messages need to be downloaded again. Remote image availability still depends on the sender's image servers and the network.

## Rebuild and sign

Run from the repository root with a valid Developer ID certificate:

```sh
xcodebuild -project myMail/myMail.xcodeproj -scheme myMail \
  -configuration Release -destination 'generic/platform=macOS' \
  -derivedDataPath build/release ARCHS='arm64 x86_64' ONLY_ACTIVE_ARCH=NO \
  CODE_SIGN_STYLE=Manual \
  CODE_SIGN_IDENTITY='Developer ID Application: ZHIPING XU (5N66S29EK2)' \
  DEVELOPMENT_TEAM=5N66S29EK2 \
  CODE_SIGN_INJECT_BASE_ENTITLEMENTS=NO \
  CODE_SIGN_ENTITLEMENTS=DeveloperID.entitlements \
  OTHER_CODE_SIGN_FLAGS=--timestamp build
```

Use `notarytool store-credentials` interactively to save credentials to Keychain. Never place the app-specific password in source, a release script, or shell history. Submit an app ZIP, wait for `Accepted`, staple the app, package it into a signed DMG, submit that DMG, then staple and validate it. Generate the SHA-256 checksum only after the final stapling step.
